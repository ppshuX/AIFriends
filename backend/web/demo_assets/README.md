# 演示视觉资产

本目录中的角色图片为 AIFriends 项目专门生成的原创演示资产，没有使用第三方角色图片或品牌素材。

生成方向：

- 林澈：蓝灰色冷静学习场景，银色眼镜与蓝黑短发；
- 晚晴：奶油色与鼠尾草绿色的温暖阅读场景；
- 星遥：深青、珊瑚和芥末黄组成的活力创意工作室；
- 远川：炭黑、驼色和暮蓝组成的沉稳职业交流场景。

头像按 `512×512` WebP 保存，背景按 `900×1500` WebP 保存。背景以对应头像作为人物一致性参考生成，并在下半部保留适合白色界面文字的较暗区域。全部图片均要求无文字、无标志、无水印、无现实品牌。

`default-avatar.png` 是媒体卷为空时用于恢复 `user/photos/default.png` 的内置默认头像副本。
