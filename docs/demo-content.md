# 官方演示内容维护说明

仓库包含一组可重复安装的官方演示内容，用于解决新部署首页为空、默认头像缺失和角色音色无法选择的问题。

## 内容清单

| 角色 | 定位 | 腾讯云音色 |
| --- | --- | --- |
| 林澈 | 冷静、耐心的学习搭档 | 智小悟 `502006` |
| 晚晴 | 温暖、细腻的生活陪伴者 | 智小柔 `502001` |
| 星遥 | 活力充沛的创意搭档 | 智小敏 `502003` |
| 远川 | 沉稳、务实的职业发展教练 | 暖心阿灿 `602004` |

每个角色包含一张方形头像、一张 3:5 聊天背景、角色提示词和腾讯云音色关联。命令还会恢复默认用户头像，并安装“回复”和“记忆”两条基础系统提示词。

## 安装方式

执行数据库操作前，生产环境应先备份 SQLite 数据库。例如在 Linux 主机上：

```bash
cp backend/db.sqlite3 "backend/db.sqlite3.bak-$(date +%Y%m%d-%H%M%S)"
python backend/manage.py seed_demo_content
```

Docker 部署应在后端容器内执行管理命令，并确保数据库与 `MEDIA_ROOT` 已挂载到持久化目录。

该命令可以重复执行：

- 创建或更新禁用登录的 `aifriends-official` 作者账号；
- 按 `voice_id` 创建或更新 4 个腾讯云音色；
- 按官方作者和角色名创建或更新 4 个角色；
- 按标题和顺序号创建或更新 2 条系统提示词；
- 将仓库内演示图片复制到当前媒体存储；
- 不删除其他用户、角色、好友或消息。

## 验证

```powershell
cd backend
python manage.py test web.test_seed_demo_content --verbosity 2
```

测试会在临时数据库和临时媒体目录中连续执行两次 seed 命令，检查不会产生重复数据，并确认所有图片已写入目标媒体存储。

## 注意事项

- 演示角色使用 `tencent:<VoiceType>` 格式，需要先完成[腾讯云语音配置](tencent-cloud-tts.md)。
- seed 命令不会创建或修改任何云服务密钥。
- 角色提示词是通用默认值，正式运营前仍应根据社区规则补充内容安全、隐私和未成年人保护政策。
